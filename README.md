# Sucupam

Sucupam is a production-oriented business website built as part of the Deep Brain Reset web portfolio.

## Overview

The project demonstrates responsive frontend implementation, component-based React development, modern routing, and an AI-ready web stack designed for fast iteration and production deployment.

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Motion
- Node.js / Express dependencies
- Google Gemini integration capability

## Development Approach

Development follows an AI-assisted engineering workflow in which AI tools accelerate implementation, debugging, refactoring, and iteration. Product direction, architecture, integration, testing, and final delivery remain under human supervision.

## Local Development

```bash
npm install
npm run dev
```

Type checking:

```bash
npm run lint
```

Production build:

```bash
npm run build
```

## Security

Runtime secrets and local `.env` files are excluded from version control. The public environment example contains placeholders only.
